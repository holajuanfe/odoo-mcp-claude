# Odoo MCP for Claude (Bancada)

Free Odoo module (`bancada_mcp_claude`) that helps configure the Odoo MCP connector for Claude.
The module is free; the Odoo MCP service is a paid external service (free trial) at https://mcp-odoo.bancada.es/?utm_source=odoo_apps&utm_medium=marketplace&utm_campaign=odoo_apps_listing&utm_content=readme.
Branches `17.0`, `18.0`, `19.0`; the module lives at the repo root, as the Odoo Apps store expects.
