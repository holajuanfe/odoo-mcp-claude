Odoo MCP for Claude (Bancada)

Ask your Odoo with Claude. This module gets you connected.

Odoo MCP is a hosted connector that lets Claude read and write your Odoo data in plain language (invoices, orders, contacts, stock, CRM and any model your Odoo user can reach), always with the permissions of your Odoo user. It works with Odoo 16 to 19 (Odoo Online, Odoo.sh and on-premise). Authorization uses OAuth 2.0 and your Odoo API key is entered on the connector's authorization page, never in the chat.

What this module does

  • Adds Settings > Claude (Odoo MCP) with the connector URL to copy: https://mcp-odoo.bancada.es/mcp
  • Explains the three steps: create an API key in My Profile > Account Security, add the connector in Claude with that URL, and authorize with your Odoo URL, database and login (shown on the page).
  • Has a button that opens the standard Odoo dialog to create an API key, the same one as in Preferences > Account Security. The module never generates, reads or stores keys.
  • Links to the documentation, the sign-up page and the plans.

No external calls from the module, no telemetry, no external Python dependencies. It does not connect Claude by itself: you need the Odoo MCP service.

Quick start

  1. Install this module and open Settings > Claude (Odoo MCP).
  2. Click Create an API key (or go to My Profile > Account Security) and copy the key.
  3. In Claude, add a custom connector with https://mcp-odoo.bancada.es/mcp.
  4. Authorize with your Odoo URL, database, login and API key. Start the free trial on mcp-odoo.bancada.es.
